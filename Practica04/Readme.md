# Práctica 04 — VM Linux con control de costes en Azure

Este repositorio contiene la resolución de la Práctica 04 del módulo de Big Data.

## Objetivos

* **Estimación previa:** Cálculo del coste de los recursos (Cómputo, Discos e IP Pública) mediante la Calculadora de precios de Azure.
* **Control de presupuesto:** Creación de un Resource Group con un *Budget* (presupuesto) específico y configuración de alertas de consumo real y proyectado (Forecasted).
* **Gobernanza y etiquetado:** Aplicación de *Tags* corporativos a todos los recursos para facilitar la trazabilidad del gasto.
* **Optimización de recursos:** Implementación de apagado automático nocturno en una máquina virtual Linux (Ubuntu Standard_B2s).
* **Análisis de costes:** Monitorización del gasto diario a través de *Azure Cost Management* y comprobación empírica de la diferencia de costes entre "apagar desde el SO" y "desasignar desde el portal".
